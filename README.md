# Megabonk Data

A data-driven Megabonk guide: exact item, tome, weapon and character numbers, and the game's real formulas read from its code (v1.0.69).

Live site: https://bonk.wiki/

Source pages and build scripts are in `src/` (`python3 src/build_site.py` rebuilds `docs/`). Suggest changes with the "Suggest an edit" link on any page.

Fan-made; not affiliated with the developers of Megabonk. Game art belongs to its developers.
